# Auto-yuketang

雨课堂（慕课 / 学堂在线类课程）和学堂在线（学位课）的视频自动挂机脚本。

脚本会打开一个真实的 Edge 浏览器窗口，你登录、选好课程后，它会按章节顺序打开没看完的视频，静音、按设定倍速真实播放，播完自动进入下一个。全部播完后会重新核对一遍进度，没算完成的视频会从头再播一次。

- 观看进度由网站自己的播放器上报，脚本不伪造任何数据
- “继续观看 / 我知道了”这类提示会自动点掉
- 视频里弹出题目时，脚本会暂停并响铃提醒，**由你自己作答**，答完自动继续；长时间没人作答会先跳过这个视频
- 只负责视频；作业、考试、讨论、图文需要你自己完成，脚本最后会列出还剩哪些没做
- 登录状态保存在本地，之后运行不用再扫码
- 挂机期间阻止电脑自动睡眠；浏览器窗口可以最小化

## 使用方法（Windows）

1. 安装 [Python 3.9 或更高版本](https://www.python.org/downloads/)，安装时勾选 **Add python.exe to PATH**。
2. 下载本项目（GitHub 页面右上角 Code → Download ZIP），解压。
3. 双击 `install.bat` 安装依赖（只需一次）。
4. 双击 `start.bat` 启动：
   - 弹出的浏览器窗口里用微信扫码登录；
   - 回到黑色命令行窗口，输入要刷的课程序号（如 `1,3`，直接回车表示全部）；
   - 之后就可以挂着了，命令行里能看到实时进度。

中途关掉也没关系，下次运行会自动跳过已完成的视频。

### 学堂在线（学位课）

1. 双击 `start_xuetangx.bat` 启动，会打开学位课首页 `https://degreecourse.xuetangx.com/`。
2. 在浏览器里登录学堂在线（只有第一次需要），打开要刷的课程，**点开其中任意一个视频**。
3. 脚本识别到这门课后会自动接手：
   - 从网页加载的数据里读出章节目录和学习进度；
   - 从你点开的视频的网址学会怎么打开其他视频；
   - 然后按顺序播放没看完的视频，倍速、静音、弹窗、弹题的处理和雨课堂一样。
4. 一门课刷完后命令行会提示。还要刷别的课，就在浏览器里打开那门课并点开一个视频，脚本会接着刷；不刷了直接关掉浏览器窗口。

学堂在线和雨课堂的登录数据、日志是分开的（`browser_data_xuetangx` 文件夹、`xuetangx.log`），两个可以同时运行。

> 学堂在线的支持目前只在模拟网页上测试过。第一次使用时请留意命令行提示，有问题把 `xuetangx.log` 附上反馈。

> 脚本默认使用 Windows 自带的 Edge 浏览器。Playwright 自带的 Chromium 不支持大部分课程视频的格式，所以不要换成它。

## 配置（config.json）

| 字段 | 默认值 | 说明 |
| --- | --- | --- |
| `base_url` | `https://www.yuketang.cn` | 雨课堂地址。学校用的是长江 / 黄河 / 荷塘雨课堂的话，改成浏览器地址栏里的域名，例如 `https://changjiang.yuketang.cn` |
| `xuetangx_url` | `https://degreecourse.xuetangx.com/` | 学堂在线模式启动时打开的网址 |
| `speed` | `2.0` | 播放倍速，范围 0.5～2（播放器自带的档位）。如果发现视频播完了进度却不涨，改成 `1.0` |
| `mute` | `true` | 是否静音。开启后会把所有视频静音并把音量调为 0，播放器自己把声音恢复时也会立刻再调回 0；还会像手动操作一样点一下播放器的静音按钮，让播放器界面也显示静音（播放器本来就是静音时不会点） |
| `browser` | `msedge` | 使用的浏览器：`msedge` 或 `chrome` |
| `headless` | `false` | 无界面运行。第一次登录时会把二维码截图保存为 `login_qrcode.png` |
| `courses` | `[]` | 课程名关键词，例如 `["高等数学", "英语"]`，填了就不再询问选哪门课 |
| `classroom_ids` | `[]` | 直接指定班级 ID（在浏览器里打开课程后，网址 `studentLog/` 后面的数字） |
| `max_passes` | `2` | 播放轮数。第 1 轮播完后核对进度，没算完成的视频会在下一轮从头播放 |
| `quiz_wait_minutes` | `30` | 视频里弹题后最多等你多少分钟，超时先跳过这个视频（它会出现在最后的未完成列表里）。填 `0` 表示一直等 |

以下为高级选项，一般不需要改，需要时自己加到 config.json 里：

| 字段 | 默认值 | 说明 |
| --- | --- | --- |
| `site` | `yuketang` | 双击 `start.bat` 时用哪个平台：`yuketang`（雨课堂）或 `xuetangx`（学堂在线）。`start_xuetangx.bat` 总是用学堂在线 |
| `chapter_wait_seconds` | `30` | 打开课程页后等待章节目录加载的秒数 |
| `manual_wait_seconds` | `300` | 自动找不到章节目录时，等你手动点开目录页的秒数 |
| `login_wait_seconds` | `300` | 等待扫码登录的秒数 |
| `course_page` | `{base_url}/v2/web/studentLog/{classroom_id}` | 课程页地址格式 |
| `video_page` | 新版、旧版两个地址 | 视频页地址格式，可以写一个或一组。脚本按顺序尝试，哪个打开后有视频就一直用哪个。默认先试新版学习空间 `{base_url}/ai-workspace/lms-graph/{classroom_id}/video/{leaf_id}`，再试旧版 `{base_url}/v2/web/xcloud/video-student/{classroom_id}/{leaf_id}` |

命令行参数：`start.bat --speed 1.5` 临时修改倍速，`start.bat --all` 刷全部课程不询问，`start.bat --debug` 输出更详细的日志，`start.bat --site xuetangx` 用学堂在线（等同于 `start_xuetangx.bat`）。

## 常见问题

**提示“没有自动找到这门课的章节目录”**
按提示在浏览器里手动点开这门课，进入能看到视频列表的页面，脚本检测到就会继续。如果这门课不是慕课类课程（比如只有老师推送的课件），会被跳过。

**视频里弹出了题目**
脚本不会替你答题。它会暂停、响一声并把浏览器窗口切到前台，你在窗口里答完，脚本会自动继续播放。如果你不在电脑前，超过 `quiz_wait_minutes` 分钟后它会先跳过这个视频去播下一个；下次运行时会再次尝试这个视频。

**视频一直卡住 / 黑屏，提示“视频一直卡住，跳过”**
多半是浏览器播不了视频格式。确认 `browser` 是 `msedge` 或 `chrome`，并且电脑上装了对应浏览器。

**怎么确认倍速生效了**
雨课堂和学堂在线都是用同一套动作选倍速，和手动操作一样：
1. 把鼠标移到视频上，等控制栏出来；
2. 移到倍速按钮上，等倍速选项弹出来（没弹出就点一下按钮）；
3. 移到 2 倍选项上点击。

所以每个视频开头，浏览器窗口里会看到倍速菜单弹出一下。这一两秒里别用鼠标在浏览器窗口上晃，免得菜单被你的鼠标带走收起来；没成功的话，脚本每隔几秒会再试。视频刚加载的十几秒里，播放器还可能把倍速改回 1 倍，脚本会一直重试，直到生效。

- 命令行出现“倍速已生效：2 倍”：正常，播放器界面上也会显示 2.00X；
- “播放器最高只有 1.5 倍速……”：这门课的播放器没有 2 倍档，脚本用最高的档位；
- “倍速 120 秒内一直被播放器改回 1 倍……”：脚本还在继续尝试。如果你在播放器里手动选 2 倍也不行，说明这门课限制了倍速；如果手动可以，请把日志文件和项目目录下的 `debug_speed.png`（第一次没点成功时的截图）发出来。

每 30 秒一行的进度末尾（如 `2x  静音`）是视频实际的播放速度和声音状态。

**播放器的静音按钮**
静音按钮是个开关，点一下静音、再点一下就有声音。所以脚本会先看播放器当前是不是静音：
- 不是静音，才点一下，点完再核对一次；
- 如果点反了，会再点回来；
- 点了没反应就不再点。

不管点没点成功，视频的声音都已经被脚本直接关掉了。点成功时命令行会显示“已点击播放器的静音按钮”；播放器一般会记住静音，之后的视频通常就不用再点了。

**视频播完了，但课程进度没涨**
部分课程不认可倍速播放，把 `speed` 改成 `1.0` 再运行一次。

**想换个账号登录**
关掉脚本，删除项目目录下的 `browser_data` 文件夹（学堂在线是 `browser_data_xuetangx`），再重新运行。

**电脑会不会睡眠**
脚本运行期间会阻止系统自动睡眠，屏幕照常可以关闭。笔记本不要合盖（除非在电源设置里把合盖改成“不采取任何操作”）。

**出问题了怎么反馈**
运行日志保存在 `yuketang.log`（学堂在线是 `xuetangx.log`），反馈时附上这个文件（以及出问题时浏览器地址栏的网址）。
